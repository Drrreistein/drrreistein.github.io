## 博客配色改为紫红色

将站点主色调从蓝色系改为 fuchsia 紫红系，覆盖 styles.css + 68 个 HTML（14 个顶层页 + 53 篇文章页）。

映射表：
- `#1e3a8a` → `#701a75`（顶部渐变深色）
- `#1e40af` → `#86198f`（波浪1）
- `#3b82f6` → `#c026d3`（波浪2 / 渐变亮端 / badge）
- `#60a5fa` → `#e879f9`（波浪3）
- `#2563eb` → `#a21caf`（`--primary-blue` 主色）
- `#1a365d` → `#4a044e`（`--dark-blue` 标题）
- `rgba(37,99,235,` → `rgba(162,28,175,`
- body 背景改 `--bg-soft: #fdf8fe`

文章页模板（米色 parchment 风格）的强调色：
- `--brand` `#1B365D` → `#6b1d5e`
- `--tag-bg` `#E4ECF5` → `#f4e4f2`
